# -QuantumVault-Post-Quantum-Cryptography-PQC-Local-Filesystem
**QuantumVault** is a local, quantum-resistant encrypted filesystem. It uses post-quantum algorithms (ML-KEM/Kyber for key exchange, ML-DSA/Dilithium for signatures) with AES-256-GCM to protect files against "harvest now, decrypt later" attacks, while providing transparent encryption, integrity verification, and secure key management.
